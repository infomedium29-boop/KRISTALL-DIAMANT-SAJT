# Kristall Diamant — V42: hero fotografija bez ružičastog sloja

- Uklonjen magenta filter preko glavne fotografije na hrvatskoj i engleskoj naslovnici.
- Vraćene prirodne boje izvorne AVIF fotografije. Samo diskretna neutralna tamna sjenka pomaže čitljivosti bijelog teksta.
- Na mobilnom prikazu uklonjen je ružičasti tint koji je nastajao kroz djelomičnu neprozirnost fotografije.
- Ostatak V41 magenta palete, svih tekstova, fotografija, loga, poveznica i funkcionalnosti ostaje nepromijenjen.
- CSS cache verzija podignuta na v42 za sve stranice.
